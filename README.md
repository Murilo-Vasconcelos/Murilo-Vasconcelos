## 🚀 Projetos em destaque

### 🔐 QKD Satellite Security Prototype
Protótipo em Arduino que simula uma comunicação segura inspirada nos conceitos de **Distribuição Quântica de Chaves (QKD)**, usados em arquiteturas de segurança para bancos, governos e infraestruturas críticas. O sistema representa visualmente a emissão de fótons, a medição dos estados quânticos, o cálculo da taxa de erro (QBER) e a decisão de aceitar ou descartar a chave gerada, usando LEDs, buzzer, potenciômetro e display LCD.

Desenvolvido em equipe como parte de um desafio (Global Solution) da FIAP.

### 🎮 GoGames — Sistema de loja virtual
Loja virtual em Python, executada via terminal, simulando a compra de periféricos, hardware e acessórios gamer: navegação por catálogo, carrinho de compras, cálculo de frete por estado e fechamento de pedido. Projeto individual com foco em boas práticas de Clean Code — separação de responsabilidades, eliminação de duplicação e organização dos dados.

**Stack:** Python 3.10+ (uso de `match/case`)

[`Código`](https://github.com/Murilo-Vasconcelos/Projeto-GoGames)
